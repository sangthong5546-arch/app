# 🪟 Batch Installer - คู่มือสำหรับ Windows 11

## 🚀 เริ่มใช้งานอย่างรวดเร็ว

### ขั้นตอนที่ 1: ติดตั้ง Python (ครั้งแรกเท่านั้น)

**ตรวจสอบว่ามี Python หรือยัง:**
1. กด `Windows + R`
2. พิมพ์ `cmd` แล้วกด Enter
3. พิมพ์ `python --version`

**ถ้าขึ้น Python 3.x.x** ➜ ข้ามไปขั้นตอนที่ 2 ได้เลย!
**ถ้าขึ้น "not found" หรือเปิด Microsoft Store** ➜ ต้องติดตั้ง Python ก่อน

#### วิธีติดตั้ง Python:

**A. แบบง่าย (แนะนำ):**
1. ไปที่ https://www.python.org/downloads/
2. คลิก "Download Python 3.12.x" (ปุ่มเหลืองใหญ่)
3. เปิดไฟล์ที่ดาวน์โหลดมา
4. **สำคัญ!** ✅ ติ๊กช่อง **"Add Python to PATH"**
5. คลิก "Install Now"
6. รอให้เสร็จ (1-2 นาที)

**B. แบบ Microsoft Store (ทางเลือก):**
1. เปิด Microsoft Store
2. ค้นหา "Python 3.12"
3. คลิก Install

📖 **คำแนะนำละเอียด:** อ่านไฟล์ `INSTALL-PYTHON.md`

---

### ขั้นตอนที่ 2: รันโปรแกรม

#### วิธีที่ 1: Double-click ไฟล์ .bat (ง่ายที่สุด!)

ไปที่โฟลเดอร์ app แล้ว **double-click** ไฟล์ใดไฟล์หนึ่ง:

- **`start-web.bat`** ⭐ แนะนำ!
  - เปิด Web UI สวยงาม
  - Browser เปิดอัตโนมัติ
  - ใช้งานง่ายที่สุด

- **`start.bat`**
  - แสดงเมนูให้เลือก UI
  - เลือกได้ระหว่าง Web, CLI หรือ GUI

#### วิธีที่ 2: ใช้ Command Prompt

```cmd
cd C:\path\to\app
start-web.bat
```

## 🎯 วิธีใช้งาน Web UI

1. **เปิดโปรแกรม**
   - Double-click `start-web.bat`
   - รอ Browser เปิด (http://localhost:8080)

2. **เลือกโปรแกรม**
   - ติ๊กเลือกโปรแกรมที่ต้องการ
   - หรือคลิก "✓ เลือกทั้งหมด"

3. **ติดตั้ง**
   - คลิก "🚀 ติดตั้งโปรแกรมที่เลือก"
   - ยืนยัน
   - รอให้เสร็จ (5-20 นาที ขึ้นกับจำนวนโปรแกรม)

4. **เสร็จสิ้น!**
   - ดูผลลัพธ์ที่หน้าจอ
   - โปรแกรมพร้อมใช้งาน!

## 🐛 แก้ปัญหา

### 1. Python not found / เปิด Microsoft Store

**สาเหตุ:** Python ยังไม่ได้ติดตั้งหรือไม่อยู่ใน PATH

**วิธีแก้:**
```
1. ติดตั้ง Python จาก https://www.python.org/downloads/
2. ต้องติ๊ก "Add Python to PATH" ตอนติดตั้ง!
3. ปิด Command Prompt ที่เปิดอยู่ทั้งหมด
4. เปิดใหม่และลองอีกครั้ง
```

**หรือปิด Windows Alias:**
```
Settings > Apps > App execution aliases
ปิด (OFF): App Installer python.exe
```

### 2. หน้าต่างปิดทันที

**วิธีแก้:**
- ใช้ไฟล์ .bat แทนการรัน python โดยตรง
- ไฟล์ .bat จะรอให้กด Enter ก่อนปิด

### 3. ไฟล์ติดตั้งดาวน์โหลดไม่ได้

**วิธีแก้:**
```
1. ตรวจสอบ Firewall/Antivirus
2. ตรวจสอบการเชื่อมต่ออินเทอร์เน็ต
3. ลองติดตั้งทีละโปรแกรม
```

### 4. Permission denied

**วิธีแก้:**
```
1. คลิกขวาที่ start-web.bat
2. เลือก "Run as administrator"
```

### 5. Port 8080 is already in use

**วิธีแก้:**
```
1. ปิดโปรแกรมที่ใช้ port 8080
2. หรือแก้ไขในไฟล์ batch_installer_web.py:
   เปลี่ยน port=8080 เป็น port=8081
```
